# 小小加法家

面向小学生的极简加法训练器，使用 Vite 构建。

## 开始使用

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
pnpm preview
```

## 功能

- 随机生成 1～10 的加法题
- 答题判定与答对计分
- 连续答对统计
- 防止答对后的重复提交（`answering` / `locked` 阶段机）
- 空答案、非法数值分别提示
- 响应式布局、键盘焦点和减少动画支持

## 答题状态机

`src/main.js` 用单一 `state` 对象管理全部状态，避免"改了变量忘了改视图"：

| 阶段 | 含义 | 行为 |
| --- | --- | --- |
| `answering` | 正在作答 | 接受提交，可以计分 |
| `locked` | 本题已答对 | 拒绝一切重复提交，等待自动出下一题 |

两个关键顺序约定：

- **先锁定、后计分**：`state.phase = 'locked'` 写在 `score += 1` 之前，杜绝同题计两次分。
- **过期回调双维度校验**：计时器回调同时校验**阶段 + 题号**，覆盖"答对 → 换题 → 又答对"的竞态。

输入校验采用整数白名单 `/^\d{1,6}$/`：小数（`1.5`）、负数（`-3`）、科学计数法（`1e3`）、字母、超长数字一律判为非法；全角数字 `１２３` 先归一化为半角。表单使用 `novalidate`，把校验交回业务代码，自定义提示才能真正显示。

## 项目结构

```text
.
├─ index.html        # Vite 入口
├─ src/main.js       # 出题、判题、计分逻辑
├─ src/style.css     # 页面样式
└─ package.json      # 依赖与脚本
```

## 优化记录（可行性演练）

| 轮次 | 负责范围 | 主要改动 |
| --- | --- | --- |
| 优化一 | `src/style.css` | 提升颜色对比度、统一键盘焦点样式、按钮最小触控高度、响应式卡片布局、支持 `prefers-reduced-motion` |
| 优化二 | `src/main.js` | 题目状态与计时器管理、答对后禁用输入防止重复提交与重复计分、过期回调校验、空答案与非法数值提示 |
| 整合 | 全项目 | 两轮改动合并、构建验证通过 |
| 补丁接入 | `src/main.js` | 优化二原提交落在 `优化二/main.js` 子目录未生效，本轮接入 `src/main.js` 并移除补丁目录 |

> 验收教训：`git log -- <被分配的文件>` 必须出现该协作者的提交，否则 PR 视为未生效。
